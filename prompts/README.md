# Prompts

Original prompts for admins, security teams and champions. Replace the text in `[brackets]`. Review answers before acting: Copilot only sees what the signed-in user can access.

## Readiness and oversharing

- `Summarise the SharePoint sites I own that contain files shared with "Everyone except external users" or with large groups, and list what kind of content each holds.`
- `List documents in [site name] whose titles suggest HR, finance, legal or credentials content, so I can check their permissions.`
- `Draft a one-page plain-language explainer for site owners on why broad sharing matters now that Copilot can surface content they can open.`

## Governance

- `Turn this list of agents into a register with columns: name, owner, purpose, data sources, who can use it, last reviewed. Flag any missing owner. [paste list]`
- `Write a 90-day review checklist for Copilot Studio agents shared with more than [number] people.`

## Licensing and adoption

- `From this usage export, list users with a Copilot licence and no activity in 30 days, grouped by department, and suggest one outreach message for each group. [paste data]`
- `Write a 5-question pulse survey that measures whether Copilot saves time without asking for sensitive information.`

## Endpoint (Intune)

- `Summarise this month's Intune release notes into: breaking changes, new features I should pilot, and deprecations with dates. [paste notes]`
- `Draft a pilot plan for rolling out [Intune feature] to 5 percent of devices, with success measures and rollback steps.`

No real tenant data should be pasted into public tools. Contributions welcome via [CONTRIBUTING.md](../CONTRIBUTING.md).
