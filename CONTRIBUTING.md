# Contributing

Thanks for helping. Please open a pull request.

## Add a resource

- Put it in the section that fits best, in alphabetical order where practical.
- Use this format: `- [Name](https://link) - One sentence that starts with a capital letter and ends with a period.`
- Link to the original source, not a copy or a search result.
- Only add things that are free to read, currently maintained and about Microsoft 365 Copilot, its agents, or the security, governance and endpoint work around them.
- Write the description in your own words. Do not paste marketing text.
- Say so in the description if a resource is a preview or promotes a paid product.

## Add a skill or prompt

- Skills go in `skills/<name>/SKILL.md`. The folder name must match the `name` in the front matter (lowercase, hyphens).
- Do not include tenant IDs, secrets, customer names or real user data.
- Say what you tested and where.

## Fix or remove

Broken links, outdated items and corrections are welcome. Open an issue or a pull request.
